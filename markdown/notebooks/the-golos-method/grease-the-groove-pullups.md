# Grease the Groove — Pull-Ups

## Description

Grease the Groove (GTG) is a high-frequency, sub-maximal training method popularized by Pavel Tsatsouline. The core principle: strength is a skill, and skills are best practiced often and fresh. 

### Beginner — Building the First Rep
```time
(8) 1:00 EMOM
  1|2 Assisted Pullup or Negatives
```

### Intermediate — Daily GTG
```time
(10)
  1|2|3 Pullups  
```
*Perform one set every 60-90 minutes during waking hours. Do not go to failure.*

### Advanced — Weighted GTG
```time
(10)
  2|3 Weighted Pullup 10|20|30lb  
```
